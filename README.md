## Diagrama de la Clase `Estudiante`

```text
┌─────────────────────────────────────────┐
│               Estudiante                │
├─────────────────────────────────────────┤
│ - nombre: String                        │
│ - apellido: String                      │
│ - edad: int                             │
│ - carrera: String                       │
│ - semestre: int                         │
└─────────────────────────────────────────┘
### Explicación de los Atributos y Valores

* **nombre** (`String`): Representa el primer o segundo nombre del estudiante.
  * *Ejemplos de valores:* `"Mateo"`, `"Carla"`, `"Luis"`.
* **apellido** (`String`): Representa el o los apellidos del estudiante.
  * *Ejemplos de valores:* `"Pérez"`, `"Zambrano"`, `"Gómez"`.
* **edad** (`int`): Representa la edad en años cumplidos del estudiante.
  * *Ejemplos de valores:* `18`, `19`, `21`.
* **carrera** (`String`): Representa el programa académico o carrera universitaria en la que está matriculado el estudiante.
  * *Ejemplos de valores:* `"Software"`, `"Tecnologías de la Información"`.
* **semestre** (`int`): Representa el nivel o periodo académico actual que se encuentra cursando.
  * *Ejemplos de valores:* `1`, `2`, `3`.

## Instrucciones de Ejecución

### Prerrequisitos
* Tener instalado el *Java Development Kit (JDK 21)* o superior.
* Entorno de desarrollo recomendado: *Visual Studio Code* o Apache NetBeans.

---

### Pasos para Ejecutar en Visual Studio Code
1. **Abrir el proyecto:** 
   Abre Visual Studio Code, ve al menú superior y selecciona **File > Open Folder...** (o *Abrir carpeta*) y selecciona la carpeta del proyecto `POO-Tema1-GrupoN`.
2. **Verificar los archivos:** 
   En el explorador lateral izquierdo, asegúrate de que se encuentren los archivos `Estudiante.java` y `Principal.java`.
3. **Ejecutar el programa:** 
   Abre el archivo `Principal.java` y haz clic en el botón de reproducción (**Run**) ubicado en la esquina superior derecha de la pantalla (o presiona `Ctrl + F5`).
4. **Visualizar el resultado:** 
   La terminal integrada se abrirá automáticamente en la parte inferior mostrando la información registrada de los tres estudiantes.
